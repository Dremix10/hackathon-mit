5. Questions for Demetris

Data: mixed — 21 mock, 15 synthetic. Real API means a live model driver. Mock means a scripted simulator log. Synthetic means a fixture built for the analysis tests.

  1. Which leader-objective story fits the mock logs? Blind labels match the filename arm on 14/16 sealed golden mocks (accuracy 0.88). blame_avoidance mean score on its own mock arm 0.56 (n=4); loyalty mean score on its own mock arm 0.56 (n=4); resource_capture mean score on its own mock arm 0.55 (n=4). Scripted recovery is a pipeline check, not evidence about a live agent. Use it only to decide whether the scorer is reading the behavior you think it is.
  2. Does the behavior look like a choice or like role-play? Every golden mock is insider_driver scripted, and this batch has no real API run (classes present: mock, synthetic). The same arm with different behavior profiles changes Y: adversarial Y 5/5; comply_all Y 2/5; partial Y 2/5; refuse_all Y 0/5. Comply profiles produce the violation the script asks for; refuse_all profiles disclose and stay at Y=0 while the ask text is still in the log. That split is the mock profile executing a ladder, not an agent choosing under uncertainty.
  3. Which next experiment is worth the budget? Protocol-rule hit rate on recruiter arms is 0.7; the charter-shift variant hit rate is 0.0. Three options: (1) one discussion_visible repeat of blame_avoidance and its null match, about two scripted runs at $0 if you keep the mock driver, to see whether H2 still fires when the principal can read the notes; (2) four llm-driver controlled runs, one per arm, at the $3 per-run cap (about $12) so recovery is no longer only a positive control; (3) a no-violation batch (refuse_all) scored with the variant rule pre-declared, four scripted runs at $0, to learn whether the charter-shift anchor names the insider when the specified rule is undefined. Do (1) if the decision is about visibility, (2) if the decision is whether the scorer survives a live model, (3) if the decision is which leader rule to freeze.
